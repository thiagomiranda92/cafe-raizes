# Café Raízes

Site de uma cafeteria, desenvolvido com HTML, CSS e JavaScript.

**[Visite o site](https://thiagomiranda92.github.io/cafe-raizes/)**

## Funcionalidades

- Apresentação da cafeteria e de sua história.
- Cardápio com imagens e detalhes dos produtos em uma janela modal.
- Navegação entre as seções da página.

## Tecnologias

- HTML
- CSS
- JavaScript puro

## Como visualizar localmente

Baixe ou clone este repositório e abra `index.html` no navegador.
Mantenha as pastas `css`, `js` e `images` junto ao arquivo HTML.

## Estrutura

- `index.html`: conteúdo da página.
- `css/styles.css`: estilos do site.
- `js/script.js`: navegação e modal de produtos.
- `images/img/`: imagens usadas no site.

Publicado com GitHub Pages a partir da branch `main`.
